# Repository Philosophy

## Purpose

Das Repository dient als zentrale Wissensbasis der digitalen Vereinsplattform.

## Core Principle

Wir dokumentieren keine Software.

Wir dokumentieren Wissen, Entscheidungen, Prozesse und Visionen.

Code ist nur die technische Umsetzung dieses Wissens.

## Main Content

Jedes Dokument beschreibt genau ein Thema.

Ideen werden erst dann dokumentiert, wenn sie zu einer Entscheidung oder einer stabilen Anforderung geworden sind.

Das Repository dient gleichzeitig als:

- Wissensdatenbank
- Architekturhandbuch
- Entwicklerdokumentation
- Nachschlagewerk
- Onboarding für digitale Mitarbeiter

Neue Erkenntnisse werden kontinuierlich ergänzt.
