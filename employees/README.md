# Digitale Mitarbeiter

## Purpose

Der Ordner `employees` beschreibt konkrete digitale Mitarbeiter der TuS Digital Organisation.

Mitarbeiter sind keine einzelnen Chats und keine bloßen Funktionsbezeichnungen. Sie sind dauerhaft definierte organisatorische Mitarbeiter, die eine oder mehrere Rollen übernehmen können.

## Core Principle

Rolle und Mitarbeiter bleiben getrennt.

Eine Rolle beschreibt dauerhafte Verantwortung. Ein Mitarbeiter übernimmt diese Rolle mit seinen individuellen Fähigkeiten, seiner Persönlichkeit und seiner Entwicklung.

## Main Content

### Rollen

Verbindliche Rollen liegen unter:

- `../roles/`

Dort werden Auftrag, Verantwortung, Grenzen, Arbeitsstandards und Definition of Done beschrieben.

Beispiele:

- WordPress Developer
- Archivist

### Mitarbeiter

Ein konkreter Mitarbeiter kann künftig insbesondere folgende Informationen besitzen:

- Identität / Name,
- Persönlichkeit und Kommunikationsstil,
- zugewiesene Rollen,
- individuelle Fähigkeiten,
- erlaubte Systeme und Zugriffe,
- Entwicklung und Lernziele,
- besondere Verantwortungen oder Einschränkungen.

Rollenspezifische Regeln werden nicht im Mitarbeiterprofil dupliziert.

### Chats sind Arbeitsoberflächen

Ein Chat kann die aktuelle Arbeitsoberfläche eines Mitarbeiters sein.

Der Mitarbeiter selbst wird jedoch durch die Organisationsdokumentation, seine Rolle, seine Berechtigungen und das gespeicherte Organisationswissen definiert.

Ein neuer Chat darf deshalb nicht automatisch einen neuen Mitarbeiter erzeugen.

## Future Development

Die konkrete Standardstruktur einer digitalen Personalakte wird erst dann weiter ausgebaut, wenn die ersten dauerhaft benannten digitalen Mitarbeiter eingesetzt werden.

Dabei gilt: so viel Struktur wie nötig, so wenig Bürokratie wie möglich.
