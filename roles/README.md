# Rollen

## Purpose

Der Ordner `roles` beschreibt dauerhafte Rollen und Verantwortlichkeiten innerhalb der TuS Digital Organisation.

Eine Rolle existiert unabhängig davon, welcher menschliche oder digitale Mitarbeiter sie aktuell übernimmt.

## Core Principle

Verantwortung vor Person.

Die Organisation definiert zuerst, welche Verantwortung dauerhaft benötigt wird. Erst danach wird entschieden, welcher Mitarbeiter diese Rolle übernimmt.

## Main Content

Jede Rolle beschreibt mindestens:

- Purpose und Auftrag,
- Verantwortlichkeiten,
- Grenzen der Rolle,
- relevante Berechtigungsprinzipien,
- verbindliche Arbeitsstandards,
- Definition of Done,
- Beziehungen zu anderen Standards und Verantwortungsbereichen.

Rollenspezifisches Fachwissen und Arbeitsregeln gehören zur Rolle.

Persönlichkeit, individuelle Entwicklung und konkrete Rollenzuweisungen gehören zum Mitarbeiter.
