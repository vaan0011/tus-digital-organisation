# Event Manager Vision

## Purpose

Der Event Manager unterstützt den vollständigen Lebenszyklus einer Vereinsveranstaltung.

Er dient nicht nur der organisatorischen Planung, sondern verbindet Vorbereitung, Kommunikation, Durchführung, Nachbereitung und Wiederverwendung in einem gemeinsamen System.

Der Event Manager soll die ehrenamtliche Arbeit vereinfachen, Wissen sichern und verhindern, dass Veranstaltungen jedes Jahr wieder bei null geplant werden müssen.

## Core Principle

Eine Veranstaltung wird einmal zentral angelegt.

Alle organisatorischen Informationen, Aufgaben, Kommunikationsinhalte, Werbemittel, Teilnehmerdaten und späteren Erkenntnisse werden aus diesem zentralen Event heraus verwaltet.

Der Event Manager bildet keine einzelnen isolierten Funktionen ab, sondern den vollständigen Prozess einer Veranstaltung.

## Main Content

### 1. Lebenszyklus einer Veranstaltung

Jede Veranstaltung durchläuft grundsätzlich mehrere Phasen:

1. Planung
2. Werbung und Kommunikation
3. Vorbereitung
4. Durchführung
5. Nachbereitung
6. Archivierung
7. Wiederverwendung

Die einzelnen Funktionen des Event Managers orientieren sich an diesen Phasen.

### 2. Planung

In der Planungsphase werden alle organisatorischen Grundlagen einer Veranstaltung verwaltet.

Dazu gehören unter anderem:

- Veranstaltungsart
- Datum und Uhrzeit
- Veranstaltungsort
- Verantwortliche Personen
- Aufgaben
- Helfer
- Zeitplan
- Material
- Infrastruktur
- Lieferanten
- Genehmigungen
- Budget
- Sicherheitsanforderungen
- Abhängigkeiten zwischen Aufgaben

### 3. Werbung und Kommunikation

Die Werbung ist ein fester Bestandteil des Eventprozesses.

Aus den zentral gepflegten Veranstaltungsdaten sollen automatisch oder teilautomatisch Kommunikations- und Werbeinhalte entstehen.

Dazu gehören beispielsweise:

- Veranstaltungsseite auf der Homepage
- Social-Media-Beiträge
- Instagram-Storys
- Facebook-Beiträge
- Flyer
- Plakate
- Newslettertexte
- Texte für das Ortsblatt
- Inhalte für das Stadionheft
- Sponsorenversionen
- interne Helferinformationen

Die Details werden im Dokument `marketing-system.md` beschrieben.

### 4. Vorbereitung

Vor der Veranstaltung unterstützt das System die konkrete Einsatzplanung.

Dazu gehören:

- Aufgabenlisten
- Zuständigkeiten
- Helferschichten
- Aufbauplanung
- Materiallisten
- Bestellungen
- Raum- oder Geländeplanung
- Ablaufpläne
- Checklisten
- Kommunikationsstände
- offene Risiken

### 5. Durchführung

Während der Veranstaltung stellt der Event Manager alle relevanten Informationen übersichtlich bereit.

Dazu gehören:

- Tagesablauf
- Ansprechpartner
- Helferpläne
- Checklisten
- Notfallinformationen
- Raum- oder Geländepläne
- Teilnehmerlisten
- Einlassinformationen
- kurzfristige Änderungen
- Status offener Aufgaben

### 6. Nachbereitung

Nach der Veranstaltung werden Ergebnisse und Erfahrungen dokumentiert.

Dazu gehören:

- Einnahmen
- Ausgaben
- Besucherzahlen
- Helfereinsatz
- Verbrauchsmengen
- Rückmeldungen
- Fotos
- Presseberichte
- Dankeskommunikation
- offene Folgeaufgaben
- Lessons Learned

### 7. Archivierung

Jede abgeschlossene Veranstaltung wird dauerhaft archiviert.

Das Archiv enthält unter anderem:

- Stammdaten der Veranstaltung
- Ablauf
- Aufgaben
- Helferpläne
- Budget
- Teilnehmerzahlen
- Verkaufszahlen
- Medien
- Dokumente
- Werbemittel
- Berichte
- Erkenntnisse

Das Archiv dient gleichzeitig als Wissensbasis für zukünftige Veranstaltungen und für die Vereinschronik.

### 8. Wiederverwendung

Wiederkehrende Veranstaltungen sollen nicht jedes Jahr neu aufgebaut werden müssen.

Eine frühere Veranstaltung kann als Vorlage kopiert werden.

Dabei können übernommen werden:

- Grundstruktur
- Aufgaben
- Checklisten
- Zeitplan
- Materiallisten
- Lieferanten
- Rollen
- Werbeformate
- Saal- oder Geländepläne
- Erfahrungswerte
- Verbrauchsmengen

Jahresabhängige Angaben werden anschließend aktualisiert.

### 9. Veranstaltungstypen

Der Event Manager unterstützt unterschiedliche Veranstaltungstypen.

Beispiele:

- Winterfeier
- Sportfest
- Jugendturnier
- Blitzturnier
- Ehrentag
- Jubiläum
- Theaterveranstaltung
- Sponsorenveranstaltung
- Mitgliederversammlung
- Vereinsausflug
- Workshop
- Sitzung
- Jugendcamp
- Maibaumfest
- Kerweveranstaltung

Jeder Veranstaltungstyp kann eigene Funktionen, Datenfelder und Prozesse aktivieren.

Beispiele:

#### Winterfeier

- Ticketverkauf
- Saalplan
- Tisch- und Platzverwaltung
- Menüwünsche
- Ehrungen
- Bühnenprogramm
- Einlassliste

#### Turnier

- Mannschaften
- Spielplan
- Schiedsrichter
- Ergebnisse
- Turnierleitung
- Kabinen
- Platzbelegung

#### Mitgliederversammlung

- Anmeldung
- Tagesordnung
- Anträge
- Teilnehmerliste
- Abstimmungen
- Protokoll

#### Sponsorenveranstaltung

- Einladungen
- Firmenzuordnung
- Ansprechpartner
- Namensschilder
- Präsentationen
- Partnerangebote
- Nachfassaktionen

### 10. Modulare Struktur

Nicht jede Veranstaltung benötigt alle Funktionen.

Die benötigten Module werden abhängig vom Veranstaltungstyp aktiviert.

Mögliche Module sind:

- Aufgabenverwaltung
- Helfermanagement
- Budgetverwaltung
- Ticketing
- Teilnehmerverwaltung
- Sitzplatzverwaltung
- Raumplanung
- Turnierverwaltung
- Marketing-System
- Dokumentenverwaltung
- Bildarchiv
- Checklisten
- Nachbereitung
- Lessons Learned

### 11. Zentrale Datenhaltung

Informationen sollen nur einmal gepflegt werden.

Beispielsweise werden Veranstaltungsname, Datum, Ort, Ansprechpartner und Beschreibung zentral gespeichert und anschließend in allen verbundenen Funktionen wiederverwendet.

Dadurch werden doppelte Pflege, widersprüchliche Angaben und unnötige Arbeit vermieden.

### 12. Zusammenarbeit mit anderen Systemen

Der Event Manager ist Teil der digitalen Vereinsplattform und arbeitet mit anderen Bereichen zusammen.

Dazu gehören insbesondere:

- Content Hub
- Sponsor Manager
- Mitglieder- und Kontaktdaten
- Bildarchiv
- Vereinschronik
- Aufgabenverwaltung
- Dokumentenmanagement
- Designsystem
- digitale Mitarbeiter
- Automatisierungsplattform
