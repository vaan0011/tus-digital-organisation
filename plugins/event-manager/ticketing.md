# Event Manager – Ticketing

## Purpose

Das Ticketing-Modul unterstützt Veranstaltungen mit Vorverkauf, Sitzplatzverwaltung und Teilnehmermanagement.

## Core Principle

Der Verein pflegt Ticketverkauf, Tischbelegung und Teilnehmerinformationen an einer zentralen Stelle.

Der Event Manager erzeugt daraus automatisch Saalpläne, Teilnehmerlisten und Auswertungen.

## Main Content

### Veranstaltungstypen

Beispiele:

- Winterfeier
- Jubiläumsabend
- Sponsorenabend
- Ehrungen
- Theater
- Galaveranstaltungen

### Ticketverkauf

Für jedes Ticket können folgende Informationen gepflegt werden:

- Ticketnummer
- Käufer
- Anzahl Personen
- Preis
- Zahlungsstatus
- Bemerkungen

### Sitzplatzverwaltung

Verwaltung eines Saalplans mit:

- Tischen
- Sitzplätzen
- freien Plätzen
- reservierten Plätzen
- belegten Plätzen

Jeder Gast kann einem konkreten Sitzplatz zugeordnet werden.

### Teilnehmerverwaltung

Zu jedem Teilnehmer können Informationen gespeichert werden:

- Name
- Verein
- Firma
- Ehrengast
- Ehrung
- Menüwünsche
- Bemerkungen

### Druckausgaben

Automatisch erzeugbar:

- Teilnehmerliste
- Tischliste
- Einlassliste
- Saalplan
- Namensschilder
