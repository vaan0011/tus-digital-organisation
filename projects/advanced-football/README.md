# Advanced Football

## Purpose

Dieses Projekt prüft und organisiert die sinnvolle Nutzung der Plattform `advance.football` für TuS-Trainer und -Coaches.

Ein historischer Drive-Bestand zeigt, dass der TuS bereits einen kostenlosen Vereinszugang vorbereiten bzw. Coaches für die Freischaltung melden wollte. Ob das Angebot heute noch besteht, welche Funktionen relevant sind und welche Datenschutz-/Einwilligungsanforderungen gelten, muss neu verifiziert werden.

## Core Principle

> **Kein personenbezogener Plattform-Rollout ohne aktuellen Nutzen, klare Verantwortung und saubere Einwilligungs-/Datenschutzbasis.**

Trainerdaten werden nicht aus alten Listen ungeprüft weiterverwendet.

## Main Content

### Ausgangslage

Google-Drive-Projektordner:

`https://drive.google.com/drive/folders/1X4zI6G1Qmhpgv3yiPkPMoKC6D96KFQuG`

Dort liegt eine ältere Excel-Datei `TuS-Mingolsheim_advance_football_videoplattform.xlsx` aus dem damaligen Registrierungsprozess.

Die Datei enthält personenbezogene Kontaktdaten von Coaches. Diese Daten bleiben im geschützten Drive-Artefakt und werden **nicht** nach GitHub kopiert.

### Projektziel

Zu klären sind:

- aktueller Leistungsumfang von advance.football,
- heutige Kosten bzw. Bedingungen für einen Vereinszugang,
- konkreter Nutzen für Trainer-/Jugendentwicklung,
- gewünschte Nutzergruppe,
- fachlicher Owner,
- Datenschutz, Einwilligung und Datenminimierung,
- Account-/Austrittsprozess,
- mögliche Schnittstellen zu Trainerentwicklung, Team Manager oder Video-/Analyseprozessen.
