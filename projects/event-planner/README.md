# TuS Event Planner

## Purpose

Dieses Projekt entwickelt den WordPress-basierten Event- und Turnierplaner des TuS Mingolsheim.

## Core Principle

Der Event Planner wird in kleinen, überprüfbaren Schritten entwickelt. GitHub ist die maßgebliche Quelle für Code, Entscheidungen und Entwicklungsstand.

## Main Content

Plugin-Pfad:

`plugin/verein-turnierplaner/`

Verbindlicher Projekt-Checkpoint:

`PROJECT-STATE.md`

Ein neuer Entwickler oder ein neuer Coding-Chat liest vor Arbeitsbeginn mindestens:

1. `PROJECT-STATE.md`
2. `../../roles/wordpress-developer/role.md`
3. `../../roles/wordpress-developer/development-standard.md`
4. `../../standards/iteration-and-progress.md`
5. `../../design/design-principles.md`
6. `../../design/ui-standard.md`
7. `../../design/logo.md`
8. relevante Einträge unter `../../decisions/`

## Working Rule

Der Chat ist Arbeitsraum.

Das Repository ist das Projektgedächtnis.

Langfristige Entscheidungen, ausgeschlossene Lösungswege und der letzte verifizierte Stand werden deshalb nicht ausschließlich im Chat belassen.
