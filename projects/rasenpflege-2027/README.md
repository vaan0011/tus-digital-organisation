# Rasenpflege 2027

Abgegrenztes Vorhaben zur Pflege der drei Rasenplätze einschließlich Tiefenlochung im Jahr 2027. Es ist vom laufenden Sportparkbetrieb und von Kunstrasen-/Bewässerungsprojekten getrennt.

**Verbindlicher Projektzustand:** [PROJECT-STATE.md](PROJECT-STATE.md). Dort stehen Bedarf, Kostenschätzung, offene Entscheidungen, Finanzierung und nächste Schritte. Keine zweite Statuspflege in dieser README.

Projektübersicht: [PROJECT-PORTFOLIO.md](../PROJECT-PORTFOLIO.md).
