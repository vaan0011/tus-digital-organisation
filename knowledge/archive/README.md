# Historienarchiv – Wissensdomäne

## Purpose

Dieser Bereich ist der Einstiegspunkt des Second Brain für das historische Vereinsarchiv des TuS Mingolsheim.

Er dupliziert weder Originalquellen noch operative Archivregister. Er verbindet die verbindlichen Archivregeln in GitHub mit dem lebenden Arbeits- und Quellenbestand in Google Drive.

## Core Principle

> **Die Geschichte liegt in den Quellen. Der Arbeitsstand liegt in den Registern. GitHub erklärt, wie beides verlässlich genutzt wird.**

## Main Content

### 1. Verbindliche Quellen

GitHub enthält die dauerhaft verbindlichen Regeln und die Runtime:

- `../../roles/archivist/role.md`

Google Drive bleibt Source of Truth für:

- historische Originalquellen,
- Transkriptionen und Erschließungsdokumente,
- den Master `TuS Historie – Quellenindex`,
- operative Register wie Ereignisse, Personen, Fundstücke, Unsicherheiten, Spieleinsätze und weitere Fachregister.

### 2. Aktueller Einstieg

Der kompakte organisationsweite Einstieg liegt in:

- `CURRENT-STATE.md`

Der aktuelle operative Arbeitsstand wird jedoch nicht aus GitHub abgeleitet, sondern beim Start einer Arbeitsphase aus dem live geführten Quellenindex und den zugehörigen Arbeitsprodukten gelesen.

### 3. Kein paralleles Archiv in GitHub

Historische Einzelfakten, Spielzeilen, Personendatensätze oder Transkriptionen werden nicht nur deshalb nach GitHub kopiert, damit sie dort ebenfalls vorhanden sind.

GitHub speichert nur Wissen, das für Orientierung, Arbeitsweise, Übergaben oder mehrere Rollen dauerhaft relevant ist.

### 4. Veröffentlichungen sind abgeleitete Produkte

Artikel, Chroniken, Gegner-Dossiers, Homepage-Texte und Beiträge für das Spieltagsheft werden aus der archivischen Faktenbasis erzeugt.

Sie ersetzen die zugrunde liegenden Quellen und Register nicht.

### 5. Typische Second-Brain-Inhalte der Archivdomäne

Dauerhaft relevant sind insbesondere:

- geklärte Quellen- und Identitätsregeln,
- wiederkehrende Lessons Learned zur Quellenanalyse,
- bekannte Datenlücken und Forschungsfragen,
- dokumentierte Konflikte und Unsicherheiten,
- belastbare Übergabepunkte zwischen Archiv und Kommunikation,
- Regeln für Statistiken, Rankings und Veröffentlichungsfähigkeit,
- strukturelle Erkenntnisse, die zukünftige Archivarbeit verändern.
