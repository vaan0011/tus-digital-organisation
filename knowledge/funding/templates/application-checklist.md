# Funding Application Checklist

## Purpose

Diese Checkliste dient der finalen Qualitätsprüfung vor Einreichung eines Förderantrags.

## Core Principle

Ein guter Antrag darf nicht an vermeidbaren formalen oder logischen Fehlern scheitern.

## Main Content

### 1. Förderfähigkeit

- [ ] aktuelle offizielle Förderrichtlinie geprüft
- [ ] Antragsteller / Rechtseinheit ist antragsberechtigt
- [ ] Projekt liegt im zulässigen Fördergebiet
- [ ] Zielgruppe und Vorhaben passen zum Programm
- [ ] förderfähige und nicht förderfähige Kosten geklärt
- [ ] Vorhabenbeginn-Regel geprüft
- [ ] keine förderschädliche Beauftragung / Bestellung / Vertragsbindung erfolgt
- [ ] Projektlaufzeit passt zum Förderzeitraum

### 2. Finanzierung

- [ ] Fördersatz korrekt angewendet
- [ ] Eigenanteil geklärt und intern freigegeben
- [ ] Kofinanzierung geklärt
- [ ] Umsatzsteuerbehandlung soweit erforderlich geklärt
- [ ] Finanzierungsplan rechnerisch konsistent
- [ ] Kosten durch Angebote / Schätzgrundlagen ausreichend belegt
- [ ] Vorfinanzierungs- und Liquiditätsbedarf sichtbar

### 3. Antragsstrategie

- [ ] offizielles Förderziel verstanden
- [ ] Auswahl-/Bewertungskriterien extrahiert
- [ ] Antrag beantwortet diese Kriterien sichtbar
- [ ] konkrete Problem-/Bedarfslage beschrieben
- [ ] Zielgruppen klar benannt
- [ ] Maßnahmen konkret und nachvollziehbar
- [ ] erwartete Wirkung realistisch beschrieben
- [ ] messbare oder beobachtbare Erfolgskriterien definiert
- [ ] Nachhaltigkeit / Weiterführung nach Förderende beschrieben, sofern relevant
- [ ] Rolle und Leistungsfähigkeit des TuS plausibel dargestellt

### 4. Evidenz

- [ ] Vereinskennzahlen aktuell oder als Planwerte gekennzeichnet
- [ ] Partnerzusagen / Kooperationen nicht erfunden
- [ ] Projektzahlen mit verantwortlichen Bereichen abgestimmt
- [ ] notwendige Quellen / Nachweise vorhanden
- [ ] frühere Vergleichsprojekte wurden nur als Orientierung genutzt, nicht als Bewilligungsversprechen

### 5. Formalia

- [ ] richtige Formulare / Portalversion verwendet
- [ ] Pflichtfelder vollständig
- [ ] Zeichengrenzen eingehalten
- [ ] Pflichtanlagen vollständig
- [ ] Satzung / Register / Freistellungsbescheid o. Ä. aktuell, falls gefordert
- [ ] Unterschrifts-/Vertretungsregeln geklärt
- [ ] Dateiformate und Dateigrößen eingehalten
- [ ] Benennung der Anlagen eindeutig
- [ ] Einreichungsweg getestet

### 6. Ansprechpartner / Beratung

- [ ] offene Richtlinienfragen geklärt
- [ ] Förderstelle kontaktiert, wenn fachlich sinnvoll
- [ ] relevante Gesprächsergebnisse dokumentiert
- [ ] mündliche Sonderaussagen soweit möglich abgesichert

### 7. Interne Freigabe

- [ ] Projektverantwortlicher bestätigt Inhalt
- [ ] Finanzverantwortung bestätigt Budget / Eigenanteil
- [ ] Vorstand / zeichnungsberechtigte Stelle hat erforderliche Freigabe erteilt
- [ ] Datenschutz-/Rechts-/Steuerfragen eskaliert, falls relevant

### 8. Qualitätsreview

- [ ] Antrag ist aus Sicht eines externen Gutachters verständlich
- [ ] keine widersprüchlichen Zahlen
- [ ] keine widersprüchlichen Termine
- [ ] keine internen Abkürzungen ohne Erklärung
- [ ] keine übertriebenen oder unbelegbaren Wirkungsversprechen
- [ ] klare Verbindung zwischen Bedarf → Maßnahme → Wirkung → Förderziel
- [ ] Antrag auf unnötige Wiederholungen gekürzt

### 9. Einreichung

- [ ] Einreichung vor interner Sicherheitsfrist vorgesehen
- [ ] finale Version archiviert / referenziert
- [ ] Eingangsbestätigung gesichert
- [ ] Status in GitHub auf `Eingereicht` gesetzt
- [ ] erwartbarer Entscheidungszeitraum dokumentiert
- [ ] Wiedervorlage gesetzt

### 10. Nach Entscheidung

- [ ] Ergebnis dokumentiert
- [ ] Rückfragen / Feedback dokumentiert
- [ ] bei Bewilligung: Bescheidbedingungen und Fristen extrahiert
- [ ] bei Ablehnung: Lernpunkte festgehalten
- [ ] Förderkalender / Current State aktualisiert
