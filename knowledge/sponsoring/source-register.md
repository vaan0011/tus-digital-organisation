# Sponsoring Source Register

## Purpose

Dieses Dokument hält bekannte operative Datenquellen der Sponsoring-Arbeit fest, ohne vertrauliche Inhalte unnötig in GitHub zu duplizieren.

## Core Principle

Strategie und Organisationswissen gehören ins Repository. Vertrauliche oder operative Rohdaten bleiben in der dafür geeigneten geschützten Quelle.

## Main Content

### Bekannte Quellen aus der bisherigen Arbeit

#### Sponsoren-/Unterstützerbestand

Status: `Arbeitsstand`

Es existiert eine vom Finanzbereich bereitgestellte Bestandsübersicht mit ungefähr 50 Sponsoren bzw. Unterstützern.

Die konkrete Datei, Aktualität und Pflegeverantwortung sind beim operativen Neustart zu verifizieren.

#### `Bandenwerbung1.xlsx`

Status: `Arbeitsstand`

Bekannte historische/operative Übersicht zur Bandenwerbung mit Daten über einen langen Zeitraum, in der bisherigen Arbeit ungefähr 2005–2026.

Vor Nutzung sind Speicherort, Aktualität und Datenmodell zu prüfen.

#### Sponsorenliste Spieltagsmagazin

Status: `Arbeitsstand`

Bekannte Quelle für im Spieltagsmagazin geführte Partner/Sponsoren.

Sie ist eine operative Quelle, aber nicht automatisch alleinige Source of Truth für den gesamten Partnerbestand.

#### Fotos Haupttribüne / Werbeflächen

Status: `Arbeitsstand`

Bildmaterial wurde zur Bewertung vorhandener und möglicher Werbeflächen genutzt.

#### LED-Angebot

Status: `Arbeitsstand`

Es existiert ein Angebot für den LED Media Screen mit einem bisherigen Planungswert von ungefähr 48.000 € netto.

Vor jeder verbindlichen Entscheidung ist das Originalangebot erneut zu prüfen.

### Quellenprinzip

Bei widersprüchlichen Bestandsdaten wird nicht stillschweigend eine Liste zur Wahrheit erklärt.

Stattdessen wird geklärt:

- welche Quelle welchen Zweck hat,
- wer sie pflegt,
- wie aktuell sie ist,
- welche Information fachlich maßgeblich sein soll.

### Vertrauliche Daten

GitHub enthält keine unnötigen personenbezogenen Kontaktdaten oder vertraulichen Vertrags-/Konditionsdetails aus diesen Quellen.

Falls für Organisationswissen relevant, werden Quelle, Status und Erkenntnis dokumentiert, nicht zwingend der komplette Rohdatensatz.
