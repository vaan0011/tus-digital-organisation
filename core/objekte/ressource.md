# Ressource

## Purpose

Eine Ressource beschreibt alle materiellen, räumlichen oder organisatorischen Mittel, die für die Vereinsarbeit benötigt werden.

Sie ermöglicht die gemeinsame Nutzung, Planung und Verwaltung vorhandener Ressourcen.

---

## Core Principle

Eine Ressource existiert genau einmal.

Sie kann gleichzeitig oder nacheinander von unterschiedlichen Workspaces, Veranstaltungen oder Projekten genutzt werden.

---
