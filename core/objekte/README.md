# Core-Objekte

## Purpose

Core-Objekte bilden die fachlichen Grundbausteine der digitalen Organisation.

Sie existieren unabhängig von einzelnen Plugins und werden von allen Modulen gemeinsam genutzt.

---

## Core Principle

Jedes Core-Objekt wird genau einmal beschrieben.

Plugins erweitern Core-Objekte um fachliche Fähigkeiten, erzeugen jedoch keine eigenen Versionen derselben Objekte.

---

## Main Content

Zu den Core-Objekten gehören unter anderem:

- Person
- Rolle
- Aufgabe
- Dokument
- Bild
- Ressource
- Standort
- Organisation
- Workspace

Weitere Objekte werden ergänzt, sobald sie pluginübergreifend benötigt werden.
