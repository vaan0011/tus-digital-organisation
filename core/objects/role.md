# Rolle

## Purpose

Die Rolle beschreibt eine fachliche Verantwortung innerhalb der TuS Digital Organisation.

Sie definiert nicht den Menschen, sondern dessen aktuelle Funktion innerhalb eines bestimmten Kontextes.

---

## Core Principle

Eine Rolle wird von einer Person oder einem digitalen Mitarbeiter übernommen.

Eine Person kann gleichzeitig mehrere Rollen besitzen.

Eine Rolle kann im Laufe der Zeit von unterschiedlichen Personen übernommen werden.

---

## Main Content

### Beschreibung

Rollen strukturieren die Zusammenarbeit innerhalb der Organisation.

Sie definieren Verantwortlichkeiten, Zuständigkeiten und Berechtigungen.

Beispiele:

- Vorstand
- Trainer
- Betreuer
- Helfer
- Sponsorenbeauftragter
- Presse
- Fotograf
- Kassierer
- Turnierleitung
- Digitaler Mitarbeiter

---

### Stammdaten

Eine Rolle besitzt unter anderem:

- Name
- Beschreibung
- Kategorie
- Verantwortungsbereich
- Status

---

### Fähigkeiten

Eine Rolle kann:

- Verantwortlichkeiten übernehmen
- Berechtigungen erhalten
- Aufgaben verwalten
- Entscheidungen treffen
- Workspaces zugeordnet werden

---

### Beziehungen

Eine Rolle kann verbunden sein mit:

- Personen
- Digitalen Mitarbeitern
- Veranstaltungen
- Aufgaben
- Dokumenten
- Workspaces
- Organisationen

---

### Ereignisse

Eine Rolle kann:

- erstellt werden
- übernommen werden
- abgegeben werden
- deaktiviert werden
- archiviert werden

---

### Verantwortlichkeit

Rollen bündeln Verantwortung.

Berechtigungen werden bevorzugt Rollen und nicht einzelnen Personen zugewiesen.

---

### Ansichten

Je nach Rolle verändert sich die Sicht auf dieselben Daten.

Dadurch erhält jeder Benutzer genau die Informationen und Funktionen, die für seine Verantwortung notwendig sind.
