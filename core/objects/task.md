# Aufgabe

## Purpose

Die Aufgabe ist die kleinste organisatorische Arbeitseinheit der TuS Digital Organisation.

Sie beschreibt eine konkrete Tätigkeit, die von einer Person oder einem digitalen Mitarbeiter durchgeführt werden soll.

---

## Core Principle

Jede Aufgabe besitzt einen eindeutigen Zweck, einen Verantwortlichen und einen aktuellen Status.

Aufgaben entstehen aus Prozessen, Ereignissen oder manuellen Entscheidungen.

---

## Main Content

### Beschreibung

Aufgaben strukturieren die gesamte organisatorische Arbeit.

Sie können manuell erstellt oder automatisch durch Ereignisse, Vorlagen oder digitale Mitarbeiter erzeugt werden.

Eine Aufgabe gehört niemals ausschließlich zu einem Plugin.

Sie kann Bestandteil beliebiger Workspaces sein.

---

### Stammdaten

Eine Aufgabe besitzt unter anderem:

- Titel
- Beschreibung
- Status
- Priorität
- Kategorie
- Verantwortlicher
- Ersteller
- Fälligkeitsdatum
- Zeitaufwand
- Fortschritt

---

### Fähigkeiten

Eine Aufgabe kann:

- erstellt werden
- geplant werden
- delegiert werden
- begonnen werden
- pausiert werden
- abgeschlossen werden
- archiviert werden
- bewertet werden

---

### Beziehungen

Eine Aufgabe kann verbunden sein mit:

- Person
- Rolle
- Veranstaltung
- Projekt
- Dokument
- Sponsor
- Ressource
- Workspace
- Checkliste
- Wissenseintrag

Aufgaben können voneinander abhängig sein.

---

### Ereignisse

Eine Aufgabe kann unter anderem:

- erstellt
- übernommen
- begonnen
- abgeschlossen
- verschoben
- eskaliert
- archiviert

werden.

Diese Ereignisse können weitere Prozesse auslösen.

---

### Verantwortlichkeit

Jede Aufgabe besitzt mindestens einen Verantwortlichen.

Zusätzlich können Beobachter, Vertreter oder digitale Mitarbeiter beteiligt sein.

---

### Ansichten

Aufgaben können beispielsweise angezeigt werden als:

- Meine Aufgaben
- Aufgaben eines Workspaces
- Aufgaben einer Veranstaltung
- Aufgaben einer Rolle
- Überfällige Aufgaben
- Aufgaben eines digitalen Mitarbeiters
