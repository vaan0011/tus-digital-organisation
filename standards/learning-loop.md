# Learning Loop Standard

## Purpose

Dieses Dokument beschreibt, wie die TuS Digital Organisation aus realer Arbeit neue Standards, Wissen und bessere Arbeitsweisen entwickelt.

## Core Principle

Wir versuchen nicht, jede zukünftige Situation im Voraus zu regeln.

Wir schaffen ein stabiles Fundament und verbessern es anhand echter Erfahrungen.

## Main Content

### 1. Lernen entsteht aus Arbeit

Jede Aufgabe kann neue Erkenntnisse liefern über:

- fehlende Regeln,
- unnötige Komplexität,
- wiederkehrende Fehler,
- bessere Abläufe,
- unklare Verantwortlichkeiten,
- neues Organisationswissen.

Diese Erkenntnisse werden nicht nur für den Einzelfall genutzt.

### 2. Einzelfall zuerst sauber lösen

Neue Regeln werden nicht vorschnell formuliert.

Zuerst wird der konkrete Fall verstanden und innerhalb der bestehenden Prinzipien gelöst.

Erst danach wird geprüft, ob daraus eine wiederverwendbare Regel entsteht.

### 3. Wiederholung macht aus Erfahrung einen Standard

Eine neue Guideline ist besonders sinnvoll, wenn:

- dieselbe Entscheidung wiederholt getroffen werden muss,
- mehrere Mitarbeiter davon betroffen sind,
- ein relevantes Risiko reduziert wird,
- eine häufige Unsicherheit beseitigt wird,
- die Regel die Arbeit deutlich einfacher oder verlässlicher macht.

### 4. Standards werden vorgeschlagen, nicht stillschweigend verändert

Mitarbeiter dürfen jederzeit Verbesserungen vorschlagen.

Verbindliche Organisations-, Rollen-, Sicherheits- und Qualitätsstandards werden jedoch nicht im Hintergrund umgeschrieben.

Änderungen erfolgen nachvollziehbar und mit der erforderlichen Freigabe.

### 5. So wenig Regelwerk wie möglich

Vor jeder neuen Regel wird geprüft:

- Reicht eine Ergänzung an bestehender Stelle?
- Handelt es sich nur um projektspezifisches Wissen?
- Ist die Regel wirklich wiederverwendbar?
- Macht sie Arbeit einfacher oder nur formaler?

Neue Dokumente entstehen nur, wenn sie einen klaren Zweck erfüllen.

### 6. Veraltete Regeln werden verbessert

Standards sind kein Museum.

Wenn reale Arbeit zeigt, dass eine Regel unklar, unnötig oder kontraproduktiv ist, wird sie überprüft.

Die Änderung muss begründet und nachvollziehbar bleiben.

### 7. Lernen gehört zum Abschluss

Bei relevanten Aufgaben wird kurz geprüft:

- Was haben wir gelernt?
- Muss Wissen dauerhaft gesichert werden?
- Sollte ein Standard ergänzt werden?
- Gibt es eine Verbesserung für andere Rollen oder Projekte?

Nicht jede Aufgabe erzeugt eine neue Regel.

Aber keine wichtige Erkenntnis soll verloren gehen.
